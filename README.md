### Descripción de la tareas

En esta tarea se realizaron tres ejercicios, en los cuales se debía desarrollar cada uno utilizando tres formas diferentes:

1. **Lenguaje humano:** se describe paso a paso el procedimiento que debe realizar el programa.  

2. **Pseudocódigo:** se representa el algoritmo de una manera sencilla y estructurada.

3. **JavaScript:**se convierte el algoritmo en código para que pueda ser ejecutado.

*La clase Math es muy importante, ya que facilita la realización de operaciones matemáticas al momento de crear algoritmos.
La utilicé para realizar diferentes operaciones en los ejercicios. Como sus funciones ya están incluidas en JavaScript, resulta más sencillo utilizarlas e invocarlas cuando son necesarias.

Por ejemplo, utilicé funciones como Math.PI, Math.pow() y Math.sqrt().*
